# 一、每日复盘（睡前5分钟）
只复盘 4 个问题，不多写，写多了你坚持不下来。

## 1. 今天做成了什么？（亮点）
写 1～2 条即可。
例：完成了XX需求、学会了一个技巧、拒绝了无效社交、运动了20分钟。

## 2. 今天哪里没做好？（问题）
只写最关键 1 条，别自我批评。
例：拖延、玩手机太久、沟通没说清、情绪差、效率低。

## 3. 为什么会这样？（根源）
只写真实原因，不找借口。
例：时间没规划、任务太大不敢开始、容易被消息打断。

## 4. 明天怎么改？（行动）
**必须具体、可执行**，不能写空话。
错误：明天努力一点。
正确：明天9点前完成最重要任务；开番茄钟不看手机。


## 每日复盘极简模板
- 今日亮点：
- 今日问题：
- 根本原因：
- 明日改进：

就这四行，5分钟搞定。
坚持 7 天，你对自己的掌控感会明显变强。

>最关键的一句话：  
复盘不是写日记，不是自我批评，  
**复盘 = 把经历变成能力。**  
你每天只需要抓住一个核心：  
**今天哪里错了 → 为什么 → 明天怎么改**  
就足够了。
