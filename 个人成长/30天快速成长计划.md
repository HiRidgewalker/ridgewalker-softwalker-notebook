# 方法论
## 四象限法则（时间管理）
**核心：把事情按「重要 / 紧急」分成4类，只做对人生有用的**

- **第一象限：重要且紧急**
  马上要交的工作、急事、生病、截止日期
  → 立刻做

- **第二象限：重要不紧急**
  学习、成长、健身、规划、复盘、提升技能
  → **重点投入！人生变好全靠这块**

- **第三象限：紧急不重要**
  临时消息、无关电话、别人喊你帮忙
  → 少做、拒绝、委托

- **第四象限：不紧急不重要**
  刷短视频、无意义闲聊、瞎逛
  → 尽量不做

**快速用法：**
每天写待办时，标上①②③④，优先做②，少做③④。


## 番茄工作法（专注+抗拖延）
**核心：25分钟专注 + 5分钟休息，循环来**

规则超简单：
1. 设一个任务（只一件）
2. 计时 **25分钟**，手机静音，只干这件事
3. 到点休息 **5分钟**（喝水、走动）
4. 4个番茄后，休息 **15–20分钟**

**快速用法：**
不想学习/不想干活时，直接开一个25分钟番茄，不用坚持很久，压力会小很多。

## 费曼学习法（最快学会任何东西）
**核心：用“讲给小白听”的方式，倒逼自己真懂**

四步：
1. 选一个你要学的知识点
2. 试着**用最简单的话讲出来**（像讲给外行听）
3. 讲不明白的地方，就是你没懂，回去重看
4. 简化语言，去掉专业词，直到能流畅讲完

**快速用法：**
学完一个东西，立刻在备忘录写：“如果我给别人讲，我会怎么说？”
能写清楚 = 真学会。


## 第一性原理（看透本质、不跟风、不内耗）
**核心：回到最根本的事实，从头推导，不被经验绑架**

比如你迷茫时，别想“别人都怎样”，只想：
- 我真正想要什么？
- 这件事最核心的目的是什么？
- 去掉所有包装，本质是什么？

例子：
工作迷茫 → 本质是：赚钱 + 成长 + 开心
选方向 → 本质是：我擅长什么 + 市场需要什么

**快速用法：**
遇到纠结事，问自己三句：
1. 这事本质是什么？
2. 不做会怎样？
3. 做了我能承受代价吗？
