7. flex 子项被压成 0 怎么办？

长文本子项默认 min-width: auto = 内容宽度，会撑爆容器。要加 min-width: 0。

❌ 不加 min-width: 0

短
一段很长很长很长很长很长很长的中文文本会被撑爆
短

✅ 加 min-width: 0

短
一段很长很长很长很长很长很长的中文文本正常换行
短

8. 简写口诀

flex: 1 → flex: 1 1 0% → 完美平均分配
flex: auto → flex: 1 1 auto → 按内容比例分配
flex: none → flex: 0 0 auto → 不放大不缩小，固定大小
