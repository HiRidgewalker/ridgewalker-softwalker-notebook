#### 文件目录类
```

  1.pwd

    显示当前工作目录的绝对路径

  2.ls [选项] [目录/文件]

    显示当前路径的文件

    参数：

          -a 显示当前目录的所有文件和目录，包括隐藏文件

          -l 以列表的方式显示信息

          -h 文件大小以单位M显示

  3.cd [参数]

    cd ~ 回到自己的家目录

    cd .. 回到当前目录的上一级

    ./   当前路径

    ../   上一级

    cd    路径 去到该路径下

    cd /   去到主路径下

  4.mkdir [选项] 要创建的目录

    创建目录

    选项：

        -p 创建多级目录

    实例：

        创建一个空目录

            mkdir /home/dog

        创建多级目录

            mkdir -p /home/dog/white

  5.rmdir [选项] 要删除的空目录

    删除空目录

    选项：

        无

    实例：

        rm /home/dog

    说明：

        rmdir只能删除空目录，如果目录下有内容则无法删除

  6.touch

    创建空文件

    语法

        touch 文件名称

    实例：

        touch hello.txt

  7.cp

    拷贝文件到指定目录

    语法：

        cp 选项 资源/文件夹

    选项

        -r 递归复制整个文件夹

    案例：

        cp hello.txt /home/bbb (将/home/hello.txt拷贝到/home/bbb目录下)

        cp -r /home/bbb /opt (递归复制/home/bbb整个文件夹到/opt文件夹下)

  8.rm指令

    移除文件或者目录

    语法：

        rm 选项 要删除的文件或者目录

    选项

        -r：递归删除整个文件夹

        -f：强制删除不提示

    实例：

        rm /home/hello.txt （将/home/hello.txt删除）

        rm -rf /home/bbb (删除整个文件夹，不提示)

  9. mv

    移动文件与目录或者重命名

    语法：

        重命名

            mv oldname newname

        移动文件或者目录

            mv 当前目录文件名(文件的绝对路径或者相对路径) 需要移动的路径

  10.cat

    查看文件内容

    语法：

        cat 选项 要查看的文件

    选项：

        -n 显示行号

    细节：

        cat只能查看文件，不能修改文件

    实例：

        cat -n /etc/profile

  13.echo

    echo输出内容到控制台

    语法：

        echo 选项 输出内容

    案例：

        echo $PATH 输出环境变量(必须是美元符号+环境变量名：$环境变量名)

        echo $HOSTNAME  输出用户名

        echo "hello woeld" 将冒号中的字符输出到控制台上

  14.head

    显示文件的开头部分内容，默认显示文件的前10行内容

    语法：

        head 文件 （默认显示前10行）

        head -n 5 文件 （查看文件头5行内容，5可以是任意数字

    案例：

        head /home/hello.txt

  15.tail

    输出文件的尾部内容，默认是显示文件尾10行内容

    语法：

        tail 文件

        tail -n 5 文件 查看文件尾5行内容，5可以是任意数字

        tail -f 文件  实时追踪该文档所有更新 （ctrl + c 退出）

  16.>指令和>>指令

    > 输出重定向

    >> 追加

    本来打印到控制台的内容追加或者覆盖到指定的文件中

    语法：

        echo "hello" > /home/file1.txt 将hello字符重定向到file.txt文件中        （方式是覆盖）

        echo "hello" >> /home/file1.txt 将hello字符追加到file.txt文件中        （方式是追加）

    案例：

        cat ./file1.txt >> ./file2.txt 将file1中的内容追加到file2.txt

  17.ln

    语法

        ln -s 原文件或者目录 软链接名（给源文件创建一个软连接）

    案例：

        在/home目录下创建一个软连接myroot，连接到/root，目录

        ln -s /root /home/myroot

        删除软连接myroot

        rm /home/myroot

        类似于window的快捷方式

  18.history

    查看已经执行过的历史命令

    语法：

        history

        history n 查看最近使用过的n条命令

        !编号 执行历史编号为5的命令(没有空格)

  ```
