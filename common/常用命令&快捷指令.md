查看ubuntu占用内存资源前20的进程
```shell
ps -eo pid,user,%mem,rss,comm --sort=-rss | head -n 20
```

查进程相关的命令

| 目的                | 命令                              | 说明                    |
| ----------------- | ------------------------------- | --------------------- |
| 查看所有进程            | `ps aux`                        | 查看系统当前进程              |
| 按名称查进程            | `ps aux \| grep ollama`         | 会包含 `grep` 自身         |
| 按名称查进程，避免 grep 自身 | `ps aux \| grep '[o]llama'`     | 更干净                   |
| 直接查 PID           | `pgrep ollama`                  | 只输出 PID               |
| 查 PID + 完整命令      | `pgrep -a ollama`               | 推荐                    |
| 精确匹配进程名           | `pgrep -x ollama`               | 防止模糊匹配                |
| 根据 PID 查详情        | `ps -fp 202`                    | 查看 UID、PID、PPID、CMD 等 |
| 正常终止进程            | `kill 202`                      | 默认发送 `SIGTERM`        |
| 明确正常终止            | `kill -15 202`                  | 与普通 `kill 202` 基本等价   |
| 强制终止进程            | `kill -9 202`                   | 仅必要时使用                |
| 按名称终止进程           | `pkill ollama`                  | 终止匹配进程                |
| 查看 systemd 服务状态   | `systemctl status ollama`       | 查服务整体状态               |
| 停止 systemd 服务     | `sudo systemctl stop ollama`    | 推荐用于 systemd 服务       |
| 启动 systemd 服务     | `sudo systemctl start ollama`   | 启动服务                  |
| 重启 systemd 服务     | `sudo systemctl restart ollama` | 重启服务                  |
|                   |                                 |                       |

npm create vite@latest 项目名称 -- --template react

ssh本地机器代理远程机器端口
```shell
ssh -CNg -L 6006:127.0.0.1:6006 root@123.125.240.150 -p 42151

ssh -CNg -L 8000:127.0.0.1:8000 root@connect.nmb2.seetacloud.com -p 12660


ssh -p 12660 root@connect.nmb2.seetacloud.com
# 6006:127.0.0.1:6006: 本地机器端口:远程机器本地回环地址:远程机器被代理端口
# root@ip: 远程机器用户名@远程机器公网IP/域名
# -p 42151: 远程机器ssh服务启动端口
```
