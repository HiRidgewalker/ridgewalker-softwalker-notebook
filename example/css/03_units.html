CSS 单位 + 函数式值演示

对应笔记：Hub/05_CSS单位与值笔记.md。改浏览器窗口大小、看视口单位/响应式文字变化。

1. px vs em vs rem

html 根元素 font-size = 16px，下面看 em / rem 在不同父元素下的差异。

html { font-size: 16px; } 时

16px 文字
1em（基于父 = 16px）
1rem（基于 html = 16px）
2em（基于父 = 32px）
2rem（基于 html = 32px）

父元素 { font-size: 20px; } — 嵌套场景

1em（基于父 = 20px）
1rem（基于 html = 16px）
2em（基于父 = 40px）
2rem（基于 html = 32px）

→ em 跟着父走，rem 永远跟 html。em 嵌套会叠加，rem 不会。

rem 套路：1rem = 10px（计算方便）

html { font-size: 62.5%; }  → 1rem = 10px
10rem = 100px
20rem = 200px
30rem = 300px

2. 视口单位 vh / svh / dvh

桌面浏览器三个值几乎一样（看不到差异）。移动端地址栏收起/展开时差距明显——实际部署到手机看效果。

50vh（传统视口高度的一半）
50svh（最小视口高度的一半，最安全）
50dvh（动态视口高度的一半，会随地址栏变）

手机场景下 100vh 会被地址栏遮挡，建议改用 100dvh 或 100svh。

6. 函数式值：calc / min / max / clamp

calc() — 任意算术

width: calc(100% - 40px) — 父容器减去 40px

场景：height: calc(100vh - 60px) 全屏减去导航高度。

min() — 取最小

width: min(500px, 100%) — 不超过 500px，但不超过父容器

max() — 取最大

width: max(300px, 50%) — 至少 300px，但不少于一半

clamp() — 三段式（响应式神器）

下面这段文字的 font-size 随窗口大小变化：clamp(14px, 2vw, 32px)

我是 clamp 文字，缩窗口我会变小，放大窗口我会变大，但不会小于 14px 也不会大于 32px。

7. 现代响应式：clamp 替代媒体查询

传统写法要写两套 @media：

.title { font-size: 16px; }
@media (min-width: 768px) {
    .title { font-size: 24px; }
}

现代写法一行搞定：

.title { font-size: clamp(16px, 2vw, 24px); }

8. 一句话速记

rem：基于 html（响应式首选）
em：基于父（会叠加）
vh / svh / dvh：移动端优先 dvh/svh
clamp(min, 偏好, max)：流体排版
calc：加减乘除任意算
