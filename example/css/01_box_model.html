CSS 盒模型 + margin 折叠演示

对应笔记：Hub/03_CSS盒模型笔记.md。配合 DevTools 看真实占位。

1. 盒模型两种模式对比

两个 div 都写了 width: 200px; padding: 20px; border: 10px;，但实际占位不一样。

content-box（默认）
content-box
实际占位 = 200 + 40 + 20 + 30 = 290px
width: 200 + padding×2 + border×2 + margin×2 = 200+40+20+30
border-box（推荐）
border-box
实际占位 = 200 + 30 = 230px
width 已含 content+padding+border，只剩 margin×2

2. 同级兄弟 margin 折叠

两个 div 上下相邻，垂直 margin 取最大值，不是相加。

第 1 个（margin-bottom: 50px）
第 2 个（margin-top: 30px）
实际间距 = max(50, 30) = 50px（不是 80px！）

特殊情况：正负 margin 相加

第 1 个（margin-bottom: 50px）
第 2 个（margin-top: -20px）
实际间距 = 50 + (-20) = 30px

3. 父子 margin 折叠（重点）

父元素的 margin 会和第一个子元素的 margin 折叠。给父元素加 padding/border/overflow 可阻止。

无 padding/border/overflow → 父子 margin 折叠
整体向上 50px（取 max）
父有 padding: 1px → 不折叠
父 50 + 子 30 = 80px（不合并）
父有 overflow: hidden → 不折叠
父 50 + 子 30 = 80px（不合并）

4. 脱离文档流 → margin 不折叠

子元素 position: absolute 时，它不参与文档流排版，父子 margin 折叠失效。

我是 absolute（margin-top: 20px）
父元素内其他内容（看，absolute 子元素不占空间）
absolute 子元素不参与排版，margin 不再与父折叠

5. 一句话总结

margin 折叠 = 普通文档流 + 块级 + 垂直方向。
破坏任一条件就不折叠（脱离文档流 / 行内 / 水平 margin）。
