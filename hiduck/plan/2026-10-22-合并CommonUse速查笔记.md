# 合并 Common Use 三篇速查笔记

## 目标与范围

把 [工具快捷键](../../hub/工具快捷键.md)、[常用命令&快捷指令](../../hub/常用命令&快捷指令.md)、[技术名词&专有名词](../../hub/技术名词&专有名词.md) 三篇速查类笔记合并为一篇 `hub/常用速查手册.md`（拟新增），并同步 `Catalog.md`。

范围：结构整合与格式规范化；不改写内容本身（命令、快捷键、名词释义原样保留，含 ssh 示例中的真实地址）。
不包含：`markdown latex语法大全`、`语音识别` 等其余 Common Use 条目。

## 现状与关键决策

### 已确认的现状

| 项目 | 现状 |
|---|---|
| 三篇文件 | 均在 `hub/`，共 125 行，内容零散：快捷键表格 2 张、Linux 命令表 1 张、零散 shell 片段、前端名词 4 条 |
| 格式问题 | 标题全用 `#` 一级；技术名词部分是松散列表；`常用命令&快捷指令` 内「命令」与「快捷指令」混排 |
| 引用情况 | 三篇笔记仅被 `Catalog.md` 第 10–12 行引用，全仓库无其他 wiki 链接 |
| 历史遗留 | 重构前 Catalog 曾有悬空 `[[快捷指令]]` 条目，合并后该类问题自然消除 |

### 关键决策

| 编号 | 决策 | 理由 |
|---|---|---|
| A | 合并为单文件 `hub/常用速查手册.md`，`#` 作文档标题，内容用 `##`/`###` 分层 | 三篇同属「日常速查」，条目短、更新频繁，合在一起查阅成本低 |
| B | 新结构四节：`## 工具快捷键`（JetBrains / VSCode 各一 `###`）、`## Linux 常用命令`（提示符 / 进程查看 / 服务管理）、`## 快捷指令`（vite / ssh 端口代理）、`## 技术名词与专有名词`（表格化） | 按查询场景分节；「命令」与「快捷指令」按「查系统状态」与「完成一件事」拆开 |
| C | 技术名词规范为表格（名词 / 全称 / 含义），SOP 并入表格 | 原松散列表不便检索；表格与库内其他速查笔记体例一致 |
| D | 内容原样搬运：不改命令、不删条目、ssh 示例中的真实地址保留 | 「梳理」限于结构与格式，内容取舍由用户日后自行增删 |
| E | 原三篇用 `git rm` 删除（保留历史可回溯），不留空壳跳转 | 唯一引用方是 Catalog，同步更新后无悬空风险 |
