# 快速上手优先

## 规则

技术学习笔记以实用为主，开篇优先让读者「跑起来」：先建立「这是什么、解决什么问题、典型使用场景」的认知，尽早给出安装初始化步骤和最小可运行示例。环境准备、目录结构等前置内容点到为止，不铺开。

## 原因

- 笔记的第一用途是「要用的时候能立刻查到、照着做」，不是系统性教材
- 先跑起来再讲特性，读者有了体感后，后续内容更容易吸收
- 大段前置环境铺垫会劝退快速查阅的场景

## 如何应用

- 开篇一段话完成定位：是什么、解决什么问题、什么场景用
- 安装 / 初始化只给当前主流版本的最小步骤，版本对比、历史方案不展开
- 尽早给出最小可运行示例，并保证步骤完整、可直接复制执行
- 可运行示例较长时提炼到 `example/` 对应子目录，笔记中引用

## 示例

写 Redis 笔记时：开头一段说明 Redis 是内存 KV 数据库、常用作缓存与队列，接着给 `docker run redis` 启动 + `redis-cli` 连接 + 第一条 `SET/GET` 命令，三步内跑通；不先讲 Redis 的线程模型与事件循环。
