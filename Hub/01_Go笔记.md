## 1. 速查总览

### 1.1 是什么

Go（又称 Golang）是 Google 2009 年发布的**编译型、静态强类型、带垃圾回收**的编程语言。语法极简、并发是语言级一等公民、单文件可直接编译为静态二进制、部署极简（无运行时依赖）。

### 1.2 什么时候用

| 场景 | 适不适合 Go |
| --- | --- |
| 云原生后端服务（API、网关、RPC） | ✅ 主流选择 |
| CLI 工具、运维脚本 | ✅ 单二进制部署，跨平台 |
| 高并发服务（IM、推送、长连接） | ✅ goroutine + channel |
| 微服务基础设施（K8s、Docker、Prometheus 都是 Go 写的） | ✅ |
| 系统编程、底层工具 | ✅ 可直接调 syscall |
| 数据科学 / ML 训练 | ❌ 用 Python |
| 桌面 GUI / 前端 | ❌ 用 Qt / Electron / 浏览器 |
| 需要丰富三方库快速原型 | ❌ Python 生态更厚 |

### 1.3 Go vs Python（速记）

| 维度 | Go | Python |
| --- | --- | --- |
| 编译 | 编译型，单二进制 | 解释型 / 字节码 |
| 类型 | 静态强类型 | 动态强类型 |
| 编译/运行速度 | 接近 C | 慢（但有 PyPy / Cython） |
| 并发模型 | goroutine（语言级，廉价）+ channel | asyncio / threading / multiprocessing |
| 错误处理 | 返回 `error`（显式，无 try/except） | 抛异常（隐式） |
| 面向对象 | struct + interface + 嵌入 | class + 继承 |
| 三方库 | 精选，质量高 | 海量，质量参差 |
| 部署 | 单文件二进制 | 需要 runtime + 依赖 |
| 学习曲线 | 中（语法简单，但并发和接口需要适应） | 低 |

### 1.4 安装（gvm + 项目 go.mod 固定版本）

**一次性安装 gvm**（脚本：`workspace/go-sdk/install_gvm.sh`）：

```bash
# 1. 安装 bison（gvm 从源码编译 Go 时需要）
sudo apt install -y bison

# 2. 跑安装脚本（自动：装 gvm + 装 go1.23.4 + 设为默认）
bash workspace/go-sdk/install_gvm.sh
```

**启用 Go**（脚本：`workspace/go-sdk/use_go.sh`）：

```bash
# 每个新 shell 启用一次
source workspace/go-sdk/use_go.sh
# 输出：[use_go] go: go version go1.23.4 linux/amd64
```

**项目级版本固定**（`go.mod`）：

```go
module demo01_basics
go 1.23.4
```

> `go.mod` 里的 `go 1.23.4` 强制项目使用该版本语言特性，团队成员即便本机装了别的 Go 版本也会被工具链统一。

## 3. 常用命令速查

```bash
# 环境
go version                          # 看版本
go env GOPATH GOROOT GOMODCACHE     # 看环境变量

# 编译 / 跑
go run main.go                      # 编译并跑
go build -o app main.go             # 编译成二进制
go install ./...                    # 编译并装到 $GOPATH/bin

# 模块管理
go mod init <module-name>           # 初始化 go.mod
go mod tidy                         # 增删依赖（自动同步 go.sum）
go get github.com/gin-gonic/gin     # 装依赖
go mod download                     # 下载依赖到本地缓存

# 测试
go test ./...                       # 跑所有测试
go test -v -run TestXxx ./...       # 跑指定测试，verbose

# 静态检查 / 格式化
go vet ./...                        # 静态检查（必跑）
gofmt -w .                          # 格式化整个项目
goimports -w .                      # 格式化 + 自动 import（需装 golang.org/x/tools/cmd/goimports）

# 性能
go test -bench=. -benchmem          # 跑基准测试
go tool pprof cpu.prof              # 看 profile
```
