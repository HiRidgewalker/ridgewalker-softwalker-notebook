## 1. 风格确认在解决什么问题

独立项目 / 多人协作时，**视觉语言不统一**是最常见的返工来源：

- 今天这个页面用衬线字体，明天又换成无衬线 → 整体气质割裂
- 主色每次凭感觉挑 → 整站色调飘忽
- icon 风格混搭（线性和面性同框）→ 显廉价
- 插画 / 创意风格随心情切换 → 品牌识别度为零

**风格确认 = 在动手画第一稿之前，先把"语言"定下来**，所有人按同一套规则出图。

## 2. 五大确认维度（速查）

五大维度来自由旧稿 5 张图，每一维给出**是什么、典型分类、适用场景**三段。

### 2.1 字体风格

- **是什么**：决定整站的"声音"——严肃 / 亲和 / 科技 / 文艺
- **典型分类**
  - 衬线（Serif）：传统、可信、出版物气质
  - 无衬线（Sans-Serif）：现代、干净，互联网产品主流
  - 等宽（Monospace）：代码、终端、技术感
  - 手写 / 展示体：品牌字、标题字、装饰
- **选型建议**
  - 一个项目 **≤ 2 种**字体：一种正文 + 一种标题 / 品牌字
  - 中文项目注意中英文搭配（思源黑体 / 思源宋体 / 阿里巴巴普惠体等可商用）

### 2.2 颜色风格

- **是什么**：颜色体系 = 品牌识别 + 信息层级 + 情绪
- **典型分类**
  - 品牌色（Primary）：1 个主色 + 1~2 个辅色
  - 中性色（Neutral）：背景 / 文字 / 分隔线，灰阶 5~9 级
  - 状态色：成功 / 警告 / 错误 / 信息
- **经典法则**
  - **60-30-10 法则**：60% 主色（背景/留白）+ 30% 辅色（次级元素）+ 10% 强调色（CTA / 高亮）
  - **可访问性**：正文与背景对比度 ≥ 4.5:1（WCAG AA）

### 2.3 icon 风格

- **是什么**：icon 是页面上的"小型语言符号"，风格必须全局统一
- **典型分类**
  - 线性（Outline）：轻量、现代、留白多
  - 面性（Filled）：稳重、强调感、按钮内常用
  - 扁平（Flat）：无渐变无阴影，纯色块
  - 拟物（Skeuomorphism）：模拟现实质感，已过时，仅在特定复古风使用
  - 2.5D / 3D：插画化 icon，营销页常用
- **配套原则**：同一个项目**只选一种 icon 风格**，避免线性 + 面性混搭

### 2.4 插画风格

- **是什么**：用于空状态、引导页、营销 Banner、博客封面
- **典型分类**
  - 扁平（Flat）：纯色块、无渐变，工程感强
  - 2.5D：带轻微透视与阴影，立体感
  - 手绘（Hand-drawn）：亲切、人文气质
  - 拟人 / 角色化：SaaS 产品 Onboarding 常用
  - 抽象几何：科技 / 数据产品
- **选型要点**：插画风格的复杂度要和品牌调性匹配，不要 B2B 严肃工具用萌系手绘

### 2.5 创意 / 视觉风格

- **是什么**：整体美学趋势，决定页面"看上去像哪一年的设计"
- **当前（2026）流行风格速览**
  - **新拟物（Neumorphism）**：低对比、柔和阴影，已降温
  - **玻璃拟态（Glassmorphism）**：半透明 + 模糊背景，仍常见于营销页
  - **极简 / Swiss**：大留白、强排版、永不过时
  - **赛博 / Y2K**：紫粉霓虹、网格、故障感，亚文化产品常用
  - **孟菲斯（Memphis）**：几何拼贴、撞色、波点，2023 后回潮
  - **暗黑模式（Dark Mode）**：已成为标配而非风格

## 3. 如何把"风格确认"落到工作流

风格确认不是一次性审美活动，而是**项目级基础设施**：

1. **建立 Mood Board**
   - Figma 建一个 `📌 Style Guide` 文件
   - 收集 5~15 张参考图，按五大维度归类
   - 标注"我们想要"和"我们不要"两类
2. **抽象为设计 Token**
   - 颜色 → `colors/primary/500`、`colors/neutral/900` 等命名
   - 字号 → `font/size/h1`、`font/size/body`
   - 圆角 → `radius/sm`、`radius/md`、`radius/full`
   - 间距 → `spacing/4`、`spacing/8`（4 的倍数）
3. **Figma 落地**
   - 用 **Variables** 管理颜色 / 字号 / 间距（详见 [UI术语与设计风格笔记](../ui-ux-design/UI术语与设计风格笔记.md)）
   - 用 **Components** 封装按钮 / 输入框 / 卡片
   - 主题切换（亮 / 暗）靠 Variables 一键切换
4. **前端代码同步**
   - Token 转成 CSS 变量 / Tailwind config / 设计 token JSON
   - 推荐工具：[Style Dictionary](https://amzn.github.io/style-dictionary/) / [Tokens Studio](https://tokens.studio/)

## 4. 自检清单

项目启动前过一遍：

- [ ] 字体确定（中英文各 1 种，正文/标题分级）
- [ ] 颜色 Token 确定（主色 / 中性 / 状态，WCAG 对比度验证）
- [ ] icon 库选定（如 Phosphor / Lucide / Tabler），单一风格
- [ ] 插画风格确定，配 2~3 张示例
- [ ] 整体创意风格定调（极简 / 玻璃 / 暗黑等）
- [ ] Variables 与前端 Token 打通

五条都打勾，才算"风格确认"完成，可以进入详细页面设计。
