## 1. 静态资源放 `public/` 还是 `src/assets/`？

### 1.1 核心判断标准

> **不是"图片还是字体"，而是"这个资源要不要进入模块打包系统"。**

| 维度 | `public/` | `src/assets/` |
| --- | --- | --- |
| 是否被构建工具处理 | ❌ 直接拷贝到产物 | ✅ 被 import，被处理 |
| 文件名 | 保持原名 | 带 hash 指纹 |
| 引用方式 | 写死绝对路径 `/xxx.png` | `import` 进来 |
| 适合 | 公开固定文件 | 源码模块引用 |

### 1.2 放 `public/` 的场景

- **需要固定 URL 直接访问**：`/favicon.svg`、`/robots.txt`、`/manifest.webmanifest`
- **不想经过 Vite/Webpack 打包**
- **希望文件名保持不变**，方便外部系统或浏览器按约定读取
- **运行时动态拼接路径**（后端返回 `/images/a.png` 这类静态地址）

**典型例子**：

- `favicon.ico` / `favicon.svg`
- `robots.txt`
- `sitemap.xml`
- `manifest.json` / `manifest.webmanifest`
- 第三方要求固定文件名的验证文件（如百度站长验证、Google Search Console 验证）
- 很大的静态素材库，且不想让它们被 import 进构建图

### 1.3 放 `src/assets/` 的场景

- 资源会**被组件 import**
- 希望打包器帮你做**指纹文件名、缓存优化、路径重写**
- 资源和某个页面/组件**强关联**，属于源码的一部分
- 希望未使用资源能被更好地**跟随源码管理**

**典型例子**：

- 组件里引用的图片、图标、插图
- 本地字体文件
- 页面背景图
- 某个模块专用的音频、视频、svg

### 1.4 代码示例

```jsx
// ✅ src/assets/ 写法：被打包处理，文件名带 hash
import heroImage from './assets/hero.png';

export function Hero() {
    return <img src={heroImage} alt="hero" />;
}
```

```html
<!-- ✅ public/ 写法：路径写死，构建时原样拷贝 -->
<link rel="icon" href="/favicon.svg" />
<img src="/static/hero.png" alt="logo" />
```

### 1.5 一句话速记

> - `public/`：**面向"网站公开目录"的静态文件**
> - `src/assets/`：**面向"源码模块引用"的静态文件**

## 2. 常见坑

| 坑 | 说明 | 解决 |
| --- | --- | --- |
| 把图标放到 `public/` 然后 import | 拿不到 hash，无法做缓存优化 | 改放 `src/assets/` |
| 业务图片放 `src/assets/` 但不 import | 不会被任何模块引用，构建时可能被 tree-shake 掉 | 改放 `public/` |
| `public/` 里的文件路径加 `./` 或 `../` | 路径在子路由下会失效 | 必须用**绝对路径**（`/xxx.png`） |
| 把很大的视频文件放 `src/assets/` | 拖慢构建、增加 bundle 体积 | 改放 `public/` 或 CDN |
| 改 `public/` 里文件后浏览器没更新 | 浏览器缓存 | 加查询参数 `<img src="/a.png?v=2">` |

## 3. 进阶：Vite vs Webpack 的差异

| 工具 | 静态资源默认行为 |
| --- | --- |
| **Vite** | `< 4KB` 资源内联成 base64；`>= 4KB` 单独输出 |
| **Webpack 5+** | 用 `asset/resource` 输出单独文件，`asset/inline` 转 base64，`asset` 自动选 |

> 如果想精细控制，构建工具的资源处理模块都支持按类型/大小自定义规则。

## 4. 工具与扩展

- **图标库**：[iconify](https://iconify.design/)、[lucide](https://lucide.dev/) — 推荐按需 import，避免全量打包
- **雪碧图 / SVG Symbol**：小图标用 SVG `<use>` 引用，减少 HTTP 请求
- **CDN**：大文件（视频、字体包）放 CDN，不占构建产物
- **图片优化**：[sharp](https://sharp.pixelplumbing.com/)（构建时转 webp/avif）
